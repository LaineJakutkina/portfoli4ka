# Как редактировать портфолио без кода

Сайт подготовлен для Pages CMS: редактор меняет содержимое файлов в GitHub, а GitHub Pages публикует обновления. Работы, биография и тексты отдельной страницы мини-игры редактируются через интерфейс, изображения загружаются из редактора.

## Первое подключение

1. Загрузите файлы сайта, включая `.pages.yml` и папку `content`, в корень GitHub-репозитория и сохраните изменения в ветку `main`.
2. Откройте [Pages CMS](https://pagescms.org/) и войдите через GitHub.
3. При запросе доступа установите Pages CMS только для репозитория портфолио. Не выдавайте доступ ко всем репозиториям, если это не требуется.
4. Выберите репозиторий портфолио и ветку `main`. Файл `.pages.yml` задаёт поля и разделы редактора.

## Добавить работу

1. В редакторе откройте **Работы** и создайте новый элемент.
2. Выберите раздел: **Иллюстрация**, **Графика**, **Проект** или **Медиа**.
3. Заполните название и описание на русском, английском и эстонском. Если оставить перевод пустым, сайт попробует показать русский текст.
4. Загрузите изображение или обложку. Оно сохранится в папке `media` репозитория.
5. Для проекта можно указать статус, для любой работы — внешнюю ссылку. Чтобы временно убрать запись с сайта, включите **Скрыть с сайта**.
6. Сохраните изменения в GitHub. Они появятся на сайте после публикации Pages; иногда нужно подождать несколько минут и обновить страницу.

## Изменить тексты

- **Обо мне** — откройте этот раздел и отредактируйте представление, описание и принципы на трёх языках.
- **Страница мини-игры** — измените подзаголовок, заголовок, описание и статус. Сама игровая механика настраивается отдельно.

Все изменения редактор сохраняет в GitHub. Код, токены и командная строка для обычного добавления работ не нужны.
